Verify a job's on-chain commitments

Every KARMA job on Casper commits a taskHash, resultHash, and an attested rationale hash on-chain — but a hash is only a commitment, not the payload. A real MATCH/MISMATCH verdict means export_dispute_audit_packet.ts re-hashed the actual off-chain artifact (the signed receipt JSON, the plain rationale text) and compared it against the live on-chain value — not something computed in your browser. This page reads whatever that script last wrote to dispute-packets/<jobId>.json.

Defaults to job_id=5 (skill_id=3, rwa_price_oracle) — a real completed job, MATCH-verified below. Try job_id=4 instead to see the other side: the same live job, checked against a deliberately wrong artifact — a genuine MISMATCH, not a MATCH someone forgot to wire up.
